# Hello World Web Page

A simple, beautiful "Hello World" web page with a gradient background and centered greeting card.

## How to run

1. Open `index.html` directly in any web browser, or
2. Serve it with a local HTTP server:

```bash
cd /home/aryan/projects/paperclip/server/workspaces/hello-world
python3 -m http.server 8080
```

Then visit: http://localhost:8080

## Features

- Responsive design
- Animated gradient background
- Glassmorphism card with backdrop blur
- Smooth fade-in animation
