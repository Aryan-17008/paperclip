# Hi Web Page

A simple, vibrant "Hi" web page with a green gradient background and centered greeting card.

## How to run

```bash
cd /home/aryan/projects/paperclip/server/workspaces/hi-page
python3 -m http.server 8082
```

Then visit: http://localhost:8082

## Features

- Responsive design
- Animated green gradient background
- Glassmorphism card with backdrop blur
- Waving emoji animation
- Smooth pop-in entrance animation
