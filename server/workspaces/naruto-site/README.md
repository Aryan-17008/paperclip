# Hidden Leaf Village - Team 7 Showcase

A Naruto-themed character showcase page built with vanilla HTML, CSS, and JavaScript.

## Features

- Konoha leaf symbol header with "Hidden Leaf Village" title
- Character cards for Naruto, Sasuke, Sakura, and Kakashi with stats
- "Join Team 7" popup form with ninja name, rank, and specialty selection
- Orange and black color scheme with bold Bangers font
- Fully responsive design
- Smooth hover animations and transitions

## How to Run

### Option 1: Open directly in browser
```bash
cd /home/aryan/projects/paperclip/server/workspaces/naruto-site
# On WSL, you can open via Windows browser:
explorer.exe index.html
# Or serve locally and open http://localhost:8080
```

### Option 2: Local server (recommended)
```bash
cd /home/aryan/projects/paperclip/server/workspaces/naruto-site
# Python 3
python3 -m http.server 8080
# Or Node.js
npx serve -l 8080
# Or PHP
php -S localhost:8080
```

Then open http://localhost:8080 in your browser.
