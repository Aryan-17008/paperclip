# Hello World Web Page v2

A vibrant "Hello World" web page with animated shifting gradient, glassmorphism card, and a waving emoji.

## How to run

```bash
cd /home/aryan/projects/paperclip/server/workspaces/hello-world-v2
python3 -m http.server 8081
```

Then visit: http://localhost:8081

## Features

- Animated multi-color gradient background
- Glassmorphism card with backdrop blur
- Waving hand emoji animation
- Smooth pop-in entrance animation
- Fully responsive
