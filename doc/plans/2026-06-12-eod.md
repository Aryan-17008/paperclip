## What We Did Today

### 1. Model Router Cost Tracking — Full Fix (Morning)
**Problem:** Dashboard showed `$0.00 avg/task · 0 tracked` — routing decisions existed but cost was always $0.

**Root Causes Found & Fixed:**
- `issueId` wasn't in the run context snapshot → `updateRoutingDecisionCost()` couldn't find the routing decision
- `releaseIssueExecutionAndPromote()` cleared `issues.executionRunId` **before** cost tracking ran
- `hermes_local` adapter doesn't report real usage/cost from Hermes CLI

**Fixes Applied:**
- Added fallback to look up issue from `issues.executionRunId` **before** it's cleared
- Moved issue lookup **before** `releaseIssueExecutionAndPromote()` in `heartbeat.ts`
- Added token estimation from complexity when adapter doesn't report usage:
  - low: 1K input / 500 output
  - medium: 3K input / 1.5K output
  - high: 8K input / 4K output
- Added model resolution from agent adapter config
- Added `updateRoutingDecisionCost()` function that links run cost to routing decision

**Result:** Dashboard now shows non-zero costs (¢4-5 total, 4-5 tracked tasks)

**Files:** `server/src/services/heartbeat.ts`
